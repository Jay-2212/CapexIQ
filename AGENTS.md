# AGENTS.md

This project has a self-governing documentation system built for agents, by agents.

**Start at [`docs/project/INTRODUCTION.md`](./docs/project/INTRODUCTION.md).** It briefs
you on the project and the rules to follow, then points you to `docs/project/HANDOFF.md`
(current state + change log), `docs/project/DIRECTORY.md` (map of the codebase), and
`docs/project/SPEC.md` (the full product spec).

This file exists only because some coding-agent tools auto-discover `AGENTS.md` by
convention — it is a pointer, not the content. Don't add project detail here; add it to
the file it belongs in and update `docs/project/HANDOFF.md` when you do.
