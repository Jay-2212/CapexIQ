# CapexIQ project documentation

This folder contains the internal product and engineering documentation that used
to sit at the repository root.

- `INTRODUCTION.md` — project briefing and working rules.
- `CONVENTIONS.md` — code, dependency, testing, and handoff conventions.
- `DIRECTORY.md` — repository map and quick lookup.
- `HANDOFF.md` — current state and change log.
- `ISSUES.md` — known problems and open loops.
- `SPEC.md` — product specification.
- `handoff-archive/` — older handoff entries.

The root `AGENTS.md`, `CLAUDE.md`, and `README.md` remain at the root for tool
discovery and GitHub's public project landing page. This move changes organization
only; it does not change application code, runtime data, or deployed routes.
